# Distribute as a Claude Code and Codex plugin marketplace

## Description

Distribute as a Claude Code and Codex plugin marketplace

Claude Code has org-managed plugin marketplaces (Team/Enterprise admins push curated plugins bundling skills, hooks, agents, MCP) and Codex launched 'codex plugin marketplace add owner/repo' (2026-03-27). SKILL.md (agentskills.io) is read by 30+ tools; AGENTS.md is now under the Linux Foundation's Agentic AI Foundation. Reinicorn currently distributes only via the rcorn installer + 'rcorn update'. Proposal: publish crystldm/reinicorn as a marketplace whose plugin ships the skills, hooks and (later) the kb MCP server, with rcorn still the enforcing CLI; consider role/process bundles. Pin adapter upstreams (superpowers, mattpocock) as versioned packages to contain upstream drift. Related: extension-and-preset-discovery idea, multi-editor hooks. Source: landscape research 2026-10-02.
