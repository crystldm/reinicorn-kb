# Integrate with the doc systems teams already use

## Description

Integrate with the doc systems teams already use

RFC/design-doc culture mostly lives in Google Docs, Notion and Confluence; OpenAI's harness post says knowledge there 'doesn't exist' to agents, Uber ingests design docs into a graph rather than moving them to git. Backstage history (TechDocs low adoption, ADRs ending up as a Backstage plugin) suggests standalone doc tools get absorbed by portals. Options: link-out/import of external RFCs into kb specs with provenance, export of approved specs, a Backstage plugin or catalog annotation pointing at a repo's kb scope. Source: landscape research 2026-10-02.
